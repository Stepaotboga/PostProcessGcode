# G-code Конвейер для плоттера с карандашом

Программа на PyQt5 для постобработки G-code, предназначенного для рисования карандашом на плоттере (Klipper). Делает линию «живой», как будто нарисованной от руки, компенсирует стирание грифеля и показывает результат на 2D-предпросмотре с реальной толщиной линии.

## Возможности

- **Искусственный шум почерка** (два уровня шума Перлина):
  - микро-дрожание руки (высокая частота, малая амплитуда);
  - «уплывание» высоты букв и базовой линии (низкая частота, большая амплитуда);
  - плавный разгон и затухание шума на концах штрихов (зоны fade).
- **Z-offset и паузы**: через заданную длину пути вставляется `SET_GCODE_OFFSET Z_ADJUST=-l`, чтобы компенсировать стирание грифеля, а через `pause_dist` мм выполняется пауза для замены или выдвижения карандаша.
- **2D-предпросмотр** рабочей области (по умолчанию 400×435 мм) с толщиной пера в миллиметрах, которая корректно масштабируется колесом мыши. Холостые ходы можно скрыть, а рисование проиграть слайдером.
- **Обработка в фоновом потоке**: окно не зависает, есть общий прогресс-бар, название текущего этапа и кнопка «Отмена».
- **Настройки** на трёх вкладках с кнопками «Сохранить по умолчанию» и «Восстановить по умолчанию».
- Кнопка быстрой визуализации через [NC Viewer](https://ncviewer.com) (только Windows).

## Как это работает

Обработка идёт последовательно, каждый этап можно включить или выключить галочкой:

1. **Шум**
   1. Дробление коротких отрезков на шаги по 0.25 мм и смягчение острых углов.
   2. Расчёт линейного разгона коэффициентов fade от начала штриха.
   3. Расчёт затухания fade с конца штриха.
   4. Наложение шума Перлина по координатам X и Y.
   5. Удаление слишком мелких перемещений (меньше 0.2 мм).
2. **Z-offset и паузы** вставка служебных команд Klipper по пройденному пути.

Результат сохраняется рядом с исходным файлом с суффиксом `_modified`, например `drawing.gcode` → `drawing_modified.gcode`.

## Установка и запуск из исходников

Нужен Python 3.9 или новее.

```bash
git clone <адрес-репозитория>
cd <папка-проекта>

python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # Linux / macOS

pip install PyQt5 pyqtgraph numpy
python app.py
```

## Использование

1. Нажмите **«Выбрать G-code файл»** и укажите файл (`.gcode`, `.nc`, `.tap`, `.txt`).
2. Отметьте нужные обработки и при необходимости поправьте параметры на вкладках.
3. Нажмите **«Запустить конвейер преобразования»**. Кнопка блокируется на всё время обработки и построения предпросмотра. Прервать работу можно кнопкой **«Отмена»**.
4. После завершения справа появится текст итогового кода и траектория. Колесо мыши масштабирует вид, перетаскивание двигает его, слайдер «Послойная анимация» показывает порядок рисования.
5. Готовый файл `*_modified.gcode` лежит рядом с исходным.

### Вкладки настроек

| Вкладка | Что настраивается |
|---|---|
| Параметры шума | Частота и амплитуда дрожания, частота и амплитуда ухода высоты, длины зон fade |
| Параметры смещения | Стандартный z_offset `l`, выдвижение карандаша `S`, дистанция до паузы |
| Параметры вида | Толщина пера, размер стола, порог Z «карандаш опущен», допуск прореживания точек |

- **«Сохранить по умолчанию»** записывает значения текущей вкладки в `settings.json`.
- **«Восстановить по умолчанию»** читает значения из `settings.json`, а если файла нет, берёт заводские из `settings.py`.
- Чтобы вернуться к заводским настройкам, удалите `settings.json`.
- Параметры `view_margin`, `view_padding`, `grid_major` и `grid_minor` на вкладке не выводятся, их можно менять в `settings.py` или `settings.json`.

## Требования к входному G-code

Программа рассчитана на файлы, подготовленные для Klipper (например, из Vectric Aspire):

- рабочие перемещения записаны командой `G1`, холостые `G0`;
- карандаш считается опущенным, когда `G1` выполняется при `Z` ниже порога `pen_down_z` (по умолчанию 1.0 мм);
- в предпросмотре начальной точкой считается (0, 0), после `G28`;
- служебные команды `SET_GCODE_OFFSET`, `RESPOND` и `PAUSE` рассчитаны на конфигурацию Klipper с этими макросами.

Перед запуском на станке всегда проверяйте итоговый файл в предпросмотре.

## Сборка в один exe (Windows)

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name GCodePlotter app.py
```

Готовый файл появится в `dist/GCodePlotter.exe`. Подробности и частые проблемы описаны в разделе ниже.

### Важно для сборки

- В `settings.py` путь к `settings.json` должен определяться по расположению exe, а не по `__file__`, иначе настройки будут сохраняться во временную папку и пропадать после закрытия:

  ```python
  import sys
  BASE_DIR = os.path.dirname(sys.executable) if getattr(sys, "frozen", False) \
      else os.path.dirname(os.path.abspath(__file__))
  SETTINGS_FILE = os.path.join(BASE_DIR, "settings.json")
  ```

- Первый запуск `--onefile` занимает несколько секунд: exe распаковывает себя во временную папку.
- Антивирусы иногда ложно срабатывают на exe, собранные PyInstaller. Если это мешает, соберите вариант `--onedir` (без `--onefile`) и раздавайте папку целиком.
- Во время обработки программа создаёт рядом с исходным файлом папку с промежуточными файлами (`*_segments.gcode`, `*_normal.gcode` и т.д.). Её можно удалять после завершения работы.

## Известные ограничения

- Кнопка NC Viewer использует `os.startfile`, поэтому работает только в Windows.
- Предпросмотр двумерный: Z используется только для различения «рисует / не рисует».
- Парсер предпросмотра понимает только команды `G0`, `G1`, `G90`, `G91`. Дуги (`G2`/`G3`) не поддерживаются.

DEFAULT_CONST = {
    #МИКРО дрожания руки:
    "tremor_freq": 1.14, # Частота микро дрожи
    "tremor_amp": 0.18, # Амплитуда микродрожи  (мм)

    # Ступень 2: Уход высоты букв (Низкая частота, большая амплитуда)
    "height_freq": 0.09, # Частота Ступени 2: Уход высоты букв (Низкая частота, большая амплитуда)
    "height_amp": 0.41,  # Амплитуда (мм)

    # # Зоны плавного перехода fade (в миллиметрах)
    "fade_factor_1": 5.2,    # Расстояние полного нарастания для fade1  (мм)
    "fade_factor_2": 12.1,   # Расстояние полного нарастания для fade2  (мм)

    # Параметры для z_offset и паузы
    # Настройки при стирании карандаша
    "pause_dist": 5000.0,
    "defa_s": 0.75, # Выдвижение карандаша (S, мм):
    "defa_l": 0.05 # Стандартный z_offset (l, мм)
}
